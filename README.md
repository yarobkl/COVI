# COVI

**Le système d’exploitation de votre commerce.**

Front V0 de COVI : application de gestion pensée d’abord pour les réalités des petits commerces africains.

## Socle actuel
- React + TypeScript + Vite
- Interface desktop responsive
- Navigation mobile dédiée
- Tableau de bord en FCFA
- Nouvelle vente
- Mon stock
- Mes arrivages
- Routes V1 pour commandes, ballons, produits vendus, charges, statistiques et paramètres

## Lancer
```bash
npm install
npm run dev
```

Le backend, Supabase, Tauri et la synchronisation offline seront branchés après validation des parcours front.
