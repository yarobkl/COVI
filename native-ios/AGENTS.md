# COVI iOS

Pour toute demande concernant COVI sur iPhone ou TestFlight, travailler dans `native-ios/` sur `feature/covi-native-swiftui-cloud`, avec le projet `COVI.xcodeproj` et le schéma `COVI`. Vérifier ces éléments avant toute modification ou livraison.

Les 20 lots de maquettes validées (46 écrans) définissent les parcours et le rendu attendus. Comparer chaque écran à sa planche sur iPhone avant de déclarer sa conformité. Respecter le jalon de validation de chaque chantier.

L’ancienne application hybride et ses branches sont hors périmètre. Les consulter, les modifier, en importer du code ou les fusionner requiert une demande explicite de Rodrin.
